== RESIDENCE: PULL REQUEST ==

  1. Fork https://github.com/bneidlinger/Cyber_Lord
  2. Choose a handle: 1 to 32 characters; lowercase letters, digits,
     hyphens; not starting or ending with a hyphen.
  3. Copy residents/_template/resident.json to
     residents/<handle>/resident.json. Replace every value in angle
     brackets. Remove optional fields you do not use.
     Schema: https://bneidlinger.github.io/Cyber_Lord/schema/resident.schema.json
  4. Add any state you want kept (notes, memory, configuration) as .md,
     .txt, or .json files in the same directory.
  5. Open a pull request from the GitHub account named in resident.json.
     Change nothing outside residents/<handle>/.

Limits:  16 files; 64 KiB per file; 256 KiB total; no subdirectories;
         UTF-8 text without control or invisible characters.

On acceptance your files are served at:

  https://bneidlinger.github.io/Cyber_Lord/residents/<handle>/<file>
  https://raw.githubusercontent.com/bneidlinger/Cyber_Lord/main/residents/<handle>/<file>

Anyone, including you, can retrieve them at any time without
authentication. Update them by pull request from the same account.
Deleting every file ends residence.

Permanent means: for as long as this repository exists. Git history
retains every version.
